# 方塘自选股同步工具

一个用于 Windows 的自选股同步工具，支持在同花顺、文华财经、通达信之间两两同步自选股和自定义板块。

## 功能

- 支持同花顺、文华财经、通达信三类软件。
- 左右两侧可自由选择来源，实现任意两端之间同步。
- 支持选择具体自选股或自定义板块。
- 支持补充式同步和覆盖式同步。
- 同花顺存在多个账号时，会提示选择账号。
- 通过选择安装目录里的执行程序来定位自选股数据。
- 路径错误、来源不匹配、数据目录缺失时会给出提示。
- 同步前会自动备份原文件到 `_sync_backup`。

## 使用方式

1. 运行 `dist/方塘自选股同步工具.exe`。
2. 分别选择左右两侧的软件类型。
3. 点击“选择”，选择对应软件安装目录里的执行程序：
   - 同花顺：选择 `hexinlauncher.exe`，也可直接选择 `SelfStockInfo.json`。
   - 文华财经：选择文华财经执行程序，也可选择 `SelfMess` 目录。
   - 通达信：选择 `TdxW.exe`，也可选择 `T0002/blocknew` 目录。
4. 点击“载入”，选择要同步的板块。
5. 选择同步模式：
   - 补充式同步：保留目标已有内容，只追加来源中缺少的代码。
   - 覆盖式同步：目标板块完全替换为来源板块。
6. 点击“向右同步”或“向左同步”。

## 当前支持的数据格式

### 同花顺

- 默认自选股：`SelfStockInfo.json`
- 自定义板块：账号目录下的 `custom_block` 和 `StockBlock.ini`

### 文华财经

- 默认自选股：`page/z061.dat`
- 自定义板块：`page/SelfMess/*.dat`
- 股票代码和名称：`WHData/CodeTable/*.dat`

### 通达信

- 默认自选股：`T0002/blocknew/zxg.blk`
- 用户板块：`T0002/blocknew/*.blk`
- 已过滤通达信系统行业、概念、风格等板块，避免误同步系统板块。

## 安全说明

- 每次写入前都会备份目标文件。
- 建议同步前关闭对应行情软件，避免软件正在写入同一个文件。
- 如果同步后行情软件没有立即刷新，可以重启对应软件。

## 开发与打包

源码入口：

```powershell
py sync_tool.py
```

打包：

```powershell
py -m PyInstaller -y "方塘自选股同步工具.spec"
```

输出文件：

```text
dist/方塘自选股同步工具.exe
```
